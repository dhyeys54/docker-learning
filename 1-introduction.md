### 1. What is Docker

- Docker is piece of technology that helps with developing, deploying and running the application.
- Creating a package of the application: It contains application + all the dependencies
- This package can be runned everywhere.
- It uses container technology

### 2. What are containers

- Package discussed before are called container images
- On running container images we get containers
- Container are processes running on the Operating System
- Docker takes care of running containers in isolation

### 3. Containers vs VMs

-  VM would slice your resource like RAM, storage, etc.
-  Containers are processes on the operating system
-  The isolation is achieved with the help of kernel

### 3.1 Benefits of containers

- VM are heavy and longer boot process. OS takes more resources with extra utilities
- Images shift with only what is required
